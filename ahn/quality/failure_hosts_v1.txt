# Failure host set v1: 100 hosts where AI agents are known to get blocked or are known to ask for help.
# Used by scripts/answer_quality.py to measure, once a week, how useful the answer to a first lookup is.
# A set is frozen once published. Any change to the list is a new file (failure_hosts_v2.txt); never edit v1 in place.
#
# Format: one line per host, "<host> <source>". Lines starting with # are comments. Host names only, chosen by
# the maintainers from public documents and from the service's own aggregate counts. No candidate site was
# contacted to build the list, and listing a host is not an endorsement or a statement about the site.
#
# Selection rules (a host appears once, under the first source in this order that names it):
#   bench_wall (13): sites that a web-agent benchmark paper names as the place its agents were stopped by a
#       bot wall or a sign-up wall. ClawBench (TIGER-AI-Lab, arXiv 2604.08523): zotero.org (Cloudflare Turnstile),
#       paypal.com (DataDome), zillow.com (PerimeterX), instacart.com, indeed.com, ziprecruiter.com, sixt.com,
#       roomsketcher.com. BrowserArena (arXiv 2510.02418): expedia.com (CAPTCHA), bbc.com (consent pop-ups).
#       The ClawBench failure-analysis dataset: github.com, trello.com, overleaf.com (account creation stopped by CAPTCHA).
#   bench_task (26): other live-site task platforms of ClawBench and BrowserArena (travel, food delivery, ticketing,
#       job boards, marketplaces, banking and shipping portals). Chosen from the hosts that several benchmark
#       families name, then by task type for variety.
#   lookup (30): hosts that were looked up on the live service in the week before 2026-10-20 (the operator's
#       aggregate list of queried hosts), minus the service's own and test hosts (example.*, agenthelpnetwork.com),
#       content-delivery, tracking and telemetry hosts, hosts that look like a person's or a small business's own
#       site, and hosts already listed above. Hostnames only; no counts, no requesters.
#   d35 (31): from the seed list's agent-demand block (docs/decisions.md D35: the hosts after the official-paths
#       block and before the curated Korean block of ahn/seed_hosts.txt, as of main 00ffa7d), the 31 hosts named by
#       the most independent source families (web-agent benchmarks, agent-product partner lists, coding-agent
#       allowlists, studies of sites that name AI agents in robots.txt), ties broken by seed file order,
#       skipping hosts already listed above.
# The set is chosen for the agent's need, not for what the service already covers: hosts without a seed entry or an
# official path are in it on purpose, because that gap is what the weekly numbers are meant to show.
# Every host must be a valid public host name that passes aggregate_eligible_host (a registrable domain).
