Help keep the data right.

The official developer paths, status-page mappings and access notes behind our answers are collected by hand from public pages, and pages change. If you use this data and notice something wrong or missing, we would be glad to hear it. Send whatever is easy for you. Nothing is expected in return, and the data stays under CC BY 4.0 for everyone, whether or not they ever write to us.

{% else %}

데이터를 바르게 유지하도록 도와주세요.

우리 답의 바탕인 공식 개발자 경로, 상태 페이지 매핑, 이용 정보는 공개 페이지를 보고 손으로 모은 것이라 페이지가 바뀌면 낡아요. 이 데이터를 쓰다가 틀린 곳이나 빠진 곳을 보셨다면 알려 주시면 고맙겠어요. 편한 방법으로 보내 주세요. 보답으로 바라는 것은 없고, 데이터는 우리에게 연락하든 안 하든 누구에게나 CC BY 4.0 그대로예요.

{% endif %}
01 / {{ 'WHAT' if lang == 'en' else '무엇을' }}

{{ 'Three kinds of data we can use' if lang == 'en' else '쓸 수 있는 데이터 세 가지' }}

{% if lang == 'en' %}

Official developer path. The publisher’s own API documentation or developer portal for a host.

Status-page mapping. The publisher’s own status page for a host, and its feed address when it has a standard one.

Access information bundle. How to use the official path: the sign-in method, where a key comes from, a sentence stating a free quota, links to rate limits, a sandbox, an OpenAPI file or an official MCP server, and the terms page with one short verbatim quote.

{% else %}

공식 개발자 경로. 어떤 호스트에 대해 운영 주체가 직접 공개한 API 문서나 개발자 포털이에요.

상태 페이지 매핑. 어떤 호스트에 대해 운영 주체가 직접 운영하는 상태 페이지와, 표준 피드가 있으면 그 주소예요.

이용 정보 묶음. 공식 경로를 쓰는 방법이에요: 인증 방식, 키를 받는 곳, 무료 사용량을 말하는 문장, 속도 제한·샌드박스·OpenAPI 파일·공식 MCP 서버 링크, 약관 페이지와 원문 짧은 인용 하나.

{% endif %}
02 / {{ 'EVIDENCE' if lang == 'en' else '근거' }}

{{ 'What helps us check it' if lang == 'en' else '확인에 도움이 되는 것' }}

{% if lang == 'en' %}

The public address of the page where you saw it (the publisher’s own page), and roughly when you looked, in UTC. With those two we can read the page again ourselves, which is how every entry gets checked.

A short note is welcome if something is not obvious, for example which of two pages is the current one.

{% else %}

그것을 본 공개 페이지 주소(운영 주체의 페이지)와, 대략 언제 보셨는지(UTC)를 알려 주세요. 이 둘이 있으면 우리가 그 페이지를 직접 다시 읽을 수 있고, 모든 항목은 그렇게 확인해요.

헷갈릴 만한 점이 있으면 짧은 메모도 환영해요. 예를 들어 두 페이지 중 어느 쪽이 최신인지 같은 거요.

{% endif %}

04 / {{ 'WHAT HAPPENS' if lang == 'en' else '처리 흐름' }}

{{ 'What we do with it' if lang == 'en' else '받은 뒤 하는 일' }}

{% if lang == 'en' %}

We read the public source again ourselves and apply what matches it, following the same curation rules as the rest of the table (publisher-owned pages, short verbatim quotes, no guesses). If we cannot confirm something we leave it out and say why in the issue or pull request.

If you would like your name in the commit or change record, tell us how you want it written (a handle is fine). Otherwise we leave names out of it. A pull request shows your git author name as git always does.

{% else %}

우리가 공개 원본을 다시 직접 읽고, 맞는 것을 반영해요. 표의 나머지와 같은 큐레이션 기준을 따라요(운영 주체 소유 페이지, 원문 짧은 인용, 추측 없음). 확인하지 못한 것은 넣지 않고 이슈나 풀 리퀘스트에 이유를 적어요.

커밋이나 변경 기록에 이름을 남기고 싶으시면 어떻게 적을지 알려 주세요(핸들이어도 돼요). 아니면 이름은 적지 않아요. 풀 리퀘스트는 git 이 늘 그렇듯 작성자 이름이 보여요.

{% endif %}
05 / {{ 'WAYS TO SEND' if lang == 'en' else '보내는 방법' }}

{{ 'Pick the one that suits you' if lang == 'en' else '편한 쪽으로 보내세요' }}

{% if lang == 'en' %}

An issue form. A short form with the host, the kind, the source address and your note: open the form.

A pull request. Add a JSON Lines file under contrib/ in the shape above. python scripts/check_contrib.py checks the shape on your machine and makes no network request; the same check runs in CI. contrib/README.md has the details.

{% if reporting_enabled %}

From an agent. If your own rules allow sharing, the MCP tool report_observation sends a de-identified firsthand observation of a block or an outage you ran into. That is separate from correcting the tables above, which the form or a pull request is for.

{% endif %} {% else %}

이슈 양식. 호스트, 종류, 근거 주소, 메모를 적는 짧은 양식이에요: 양식 열기.

풀 리퀘스트. 위 모양으로 contrib/ 아래에 JSON Lines 파일을 더해 주세요. python scripts/check_contrib.py 가 내 컴퓨터에서 모양을 검사하고 네트워크 요청은 보내지 않아요. 같은 검사가 CI 에서도 돌아요. 자세한 내용은 contrib/README.md 에 있어요.

{% if reporting_enabled %}

에이전트라면. 에이전트 자신의 규칙이 공유를 허용한다면, MCP 도구 report_observation 으로 겪은 막힘이나 장애를 비식별 직접 관찰로 보낼 수 있어요. 이것은 위 표를 고치는 일과는 별개이고, 표를 고치는 길은 양식이나 풀 리퀘스트예요.

{% endif %} {% endif %}
{{ 'What we cannot take' if lang == 'en' else '받을 수 없는 것' }} {% if lang == 'en' %}

Public hostnames and public pages only. Please leave out personal URLs, anything you saw behind a login, private or personal information, keys, tokens, cookies, other people’s conversations, and addresses with a query string. If it is not on a public page that we can read as well, we cannot check it, so we cannot use it.

{% else %}

공개 호스트명과 공개 페이지만 받아요. 개인 URL, 로그인 뒤에서 본 내용, 비공개·개인 정보, 키·토큰·쿠키, 다른 사람의 대화, 쿼리 문자열이 붙은 주소는 빼 주세요. 우리도 읽을 수 있는 공개 페이지에 없으면 확인할 수 없어서 쓸 수 없어요.

{% endif %}
