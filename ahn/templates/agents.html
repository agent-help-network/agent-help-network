{{ 'How to act on access_profile' if lang == 'en' else 'access_profile 에 따른 행동' }}

{{ 'If robots.agents_blocked names your user-agent family, stop retrying the page: hand off to the user or use official_paths. If robots_status is refused, the host’s edge refused even a robots.txt read: expect page automation from a similar environment to be refused too and prefer official_paths. A root disallow only for unnamed crawlers (robots_wildcard_disallow) is not permission either. Any other status that is not ok (absent, redirected, invalid, error, too_large, not_public) leaves the policy layer inconclusive, not a block. Declared policy never guarantees access: CDNs, bot filters, and logins may treat a user-directed agent differently, and an allow line does not override site terms.' if lang == 'en' else 'robots.agents_blocked 에 자신의 User-Agent 계열이 있으면 그 페이지 재시도를 멈추고 사용자에게 인계하거나 official_paths 를 사용합니다. robots_status 가 refused 면 호스트 경계가 robots.txt 읽기조차 거절한 것이니 비슷한 환경의 페이지 자동화도 거절될 것으로 보고 official_paths 를 우선합니다. 이름을 지목하지 않은 크롤러만 루트를 금지한 경우(robots_wildcard_disallow)도 허락이 아닙니다. 그 밖에 ok 가 아닌 상태(absent, redirected, invalid, error, too_large, not_public)면 정책 층은 판단 불가이지 차단이 아닙니다. 선언된 정책은 접근을 보장하지 않습니다. CDN·봇 필터·로그인은 사용자 지시 에이전트를 다르게 취급할 수 있고 Allow 한 줄이 사이트 약관을 대신하지 않습니다.' }}

{{ 'provider_status is the provider’s own statement with source and fetch time; an incident may or may not explain your issue. no_reports means no matching published observation and is the normal case, not that the site works. Synthetic test observations are never public evidence.' if lang == 'en' else 'provider_status 는 출처·조회 시각이 붙은 업체 자체 발표이며 그 장애가 현재 문제의 원인인지는 알 수 없습니다. no_reports 는 일치하는 공개 관찰이 없다는 뜻으로 보통의 경우이며 사이트가 정상이라는 뜻이 아닙니다. 실패 한 건은 전체 장애가 아니고, 후속 통과도 전면 복구의 증거가 아닙니다. 가상 시험 관찰은 공개 증거로 사용하지 않습니다.' }}

{{ 'How we read hosts' if lang == 'en' else '호스트를 읽는 방법' }}

{{ 'How to act on it: send agent_vendor when you know which vendor’s robots.txt token your requests send; if agents_blocked names your token, stop retrying and hand off or use the official path. If the host’s edge refused even the robots.txt read (refused), or the file disallows the root for every crawler it does not name (robots_wildcard_disallow), prefer the official path and do not read it as permission. If robots.txt could not be read otherwise, the policy layer is inconclusive, not a block. A provider incident may or may not explain your issue.' if lang == 'en' else '행동 기준: 자기 요청이 보내는 robots.txt 토큰의 벤더를 알면 agent_vendor 를 보내십시오. agents_blocked 에 자기 토큰이 있으면 재시도를 멈추고 사람에게 인계하거나 공식 경로를 사용합니다. 호스트 경계가 robots.txt 읽기조차 거절했거나(refused), 파일이 이름을 지목하지 않은 모든 크롤러의 루트를 금지하면(robots_wildcard_disallow) 공식 경로를 우선하고 허락으로 읽지 마십시오. 그 밖의 이유로 robots.txt 를 읽지 못했다면 정책 층은 판단 불가이지 차단이 아닙니다. 업체 장애가 현재 문제의 원인인지는 알 수 없습니다.' }}

{{ 'A public apex host enters the lookup register when first searched. After a lookup we read its robots.txt and llms.txt from public addresses, under size caps, on the host or its own www. alias only, following no redirect beyond one hop to that alias. A definitive answer is cached for 24 hours; a transport failure is retried after an hour. Hosts on our public seed list are also read about once a week, even if nobody looked them up. We never attempt the task, fetch other pages, or touch login or CAPTCHA pages. Verified official status feeds are rechecked about hourly.' if lang == 'en' else '공개 루트 호스트는 처음 검색될 때 조회 목록에 들어갑니다. 조회 후 그 호스트의 robots.txt 와 llms.txt 를 공개 주소에서, 크기 한도 안에서, 그 호스트나 자기 www. 별칭에서만 읽으며 그 별칭으로 가는 한 단계 외의 리디렉션은 따라가지 않습니다. 확정된 답은 24시간 캐시하고 전송 실패는 1시간 뒤 다시 시도합니다. 공개 시드 목록의 호스트는 아무도 조회하지 않았더라도 주 1회 정도 읽습니다. 작업을 대신 시도하거나 다른 페이지를 가져오거나 로그인·CAPTCHA 페이지를 건드리지 않습니다. 확인된 공식 상태 피드는 약 1시간마다 다시 확인합니다.' }}

{{ 'Reading has side effects you should know: the hostname enters a daily lookup count, optional lookup codes are counted per hostname and hour (35 days) with a keyed IP digest specific to that hostname and day (2 days), and for eligible public apex hosts we read robots.txt and llms.txt, reusing a definitive answer for 24 hours and retrying a transport failure after an hour. Avoid sensitive hostnames. Do not poll without a task need; a later blocked task can make a fresh read with the same hostname.' if lang == 'en' else '읽기에도 알아 둘 부수효과가 있습니다. 호스트명은 일별 조회 수에 들어가고, 선택 조회 코드는 호스트명·시간별로 35일 집계하며 그 호스트명과 날짜에만 해당하는 비밀키 IP 변환값을 2일 두고, 공개 집계에 적합한 공개 루트 호스트는 robots.txt 와 llms.txt 를 읽되 확정된 답은 24시간 재사용하고 전송 실패는 1시간 뒤 다시 시도합니다. 민감한 호스트명은 피하세요. 작업 필요 없이 반복 조회하지 말고, 나중에 다시 막히면 같은 호스트명으로 새로 조회하세요.' }}
