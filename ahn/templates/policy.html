01

Who we are

Agent Help Network is an independent, free beta service{% if operator_name %} operated by {{ operator_name }}{% endif %}. {% if operator_name %}{{ operator_name }} is{% else %}Its operator is{% endif %} responsible for the data described here. Privacy questions and requests: support@agenthelpnetwork.com.

02

Data we collect

There is no account or sign-in. The check_incident tool accepts a public hostname (site_host) and optional error_class, task_step and failure_stage codes from fixed lists; full URLs, paths and query strings are rejected. {% if reporting_enabled %}The report_observation tool and the report form accept a public hostname, task step, error type, observation time, agent family, attempt actor and environment, outcome, challenge vendor and kind codes, a synthetic flag and an idempotency key; every field is a hostname, a timestamp or a value from a fixed list, and free text is not accepted. {% endif %}The website and REST API accept the same fields. Your IP address and User-Agent reach our network edge and hosting providers with every request; our database keeps only the derived counts listed under Retention, never the raw values. We do not read or store metadata an AI client may attach to a tool call, such as locale or approximate location, and we set no tracking or advertising cookies. If you email support, we receive your address and message. We do not ask for names, contact details, precise location, payment data, or conversation content, and the tools are built to refuse personal URLs and free text.

03

What the tools return

check_incident returns public, host-level information only: the host's declared robots.txt and llms.txt policy, curated official developer and status links, the provider's published status, published observations without any reporter identity, and a coarse lookup-activity band. {% if reporting_enabled %}report_observation returns a receipt with the observation and incident IDs, the review state, and a withdrawal token for that report. {% endif %}No response contains personal data about anyone else.

04

How we use data

To answer lookups; {% if reporting_enabled %}to review, de-duplicate and publish reports; {% endif %}to limit abuse and enforce request caps; to operate, secure and measure the service in aggregate, for example which public hostnames are looked up and how many tool calls succeed; and to answer support requests. We do not sell data, show ads, build profiles of people, or use your data to train AI models.

05

Who receives data

{% if reporting_enabled %}The public: reports that pass review appear on public pages and in API and MCP answers as unverified observations, with their structured fields and without any reporter identity. {% endif %}Lookup volume is shown publicly only as a coarse band. Service providers that process data for us: Cloudflare (network edge and security), Render (application hosting and database, United States), and Porkbun (email forwarding for the support address) together with the mailbox provider it forwards to. Websites we read: when we read a host's robots.txt or llms.txt, that host sees a request from our server identified as AgentHelpNetwork, carrying nothing about you. We disclose data to authorities only when the law requires it. We share it with no one else.

06

Retention

Keyed, day-specific IP digests with daily request counts: 14 days. Referral and campaign category counts, and MCP tool-call counts by result category: 90 days. Per-host daily report-intake counters: 8 days. The register of looked-up hostnames: removed after 30 days without a lookup unless the host has a connected official status feed. Daily lookup counts per public hostname and error type, and per-route request counts, contain no personal data and have no automatic deletion date. {% if reporting_enabled %}Reports have no automatic deletion date during the beta; public reads show only the last 7 days, a withdrawn report is excluded from every read, and we delete a report on request. {% endif %}Rate-limit counters stay in memory for about one minute and are never written to disk. Support emails are kept only as long as needed to handle the request. Cloudflare and Render keep their own delivery and security logs under their own retention terms.

07

Your controls

Send only public hostnames and the structured codes above. {% if reporting_enabled %}Keep the withdrawal token from your receipt: DELETE /v1/observations/{id} with that token removes your report from all reads at once. report_observation is a separate write action that your AI client may ask you to confirm; check_incident is read-only. {% endif %}You can disconnect the app in ChatGPT or remove the MCP server from your client at any time. Email support@agenthelpnetwork.com to ask what we hold about a report or request, or to correct or delete it; include the report ID if you have it. Depending on where you live, you may have further rights such as access, deletion or objection, and you can exercise them the same way. We aim to answer within 30 days.

08

Children, location and changes

The service is meant for developers and their agents, is not directed to children, and does not knowingly collect children's data. Data is processed and stored in the United States. When our practices change we update this page and the date above before the change takes effect.

01

운영 주체

Agent Help Network 는 독립 무료 베타 서비스입니다.{% if operator_name %} 운영자는 {{ operator_name }} 입니다.{% endif %} 이 방침이 설명하는 데이터의 책임은 운영자에게 있습니다. 개인정보 문의·요청: support@agenthelpnetwork.com.

02

수집하는 데이터

계정이나 로그인은 없습니다. check_incident 도구는 공개 호스트명(site_host)과, 정해진 목록에서 고르는 선택 코드 error_class·task_step·failure_stage 만 받습니다. 전체 URL·경로·쿼리 문자열은 거부합니다. {% if reporting_enabled %}report_observation 도구와 제보 양식은 공개 호스트명, 작업 단계, 오류 유형, 관찰 시각, 에이전트 계열, 시도 주체·환경, 결과, 사람 확인 업체·종류 코드, 가상 여부, 중복 방지 키만 받습니다. 모든 필드는 호스트명·시각·정해진 목록의 값이며 자유 입력 문장은 받지 않습니다. {% endif %}웹사이트와 REST API 도 같은 필드만 받습니다. 요청마다 IP 주소와 User-Agent 가 네트워크 경계·호스팅 업체에 전달되지만, 우리 데이터베이스에는 아래 보존 항목의 파생 집계만 남기고 원문은 저장하지 않습니다. AI 클라이언트가 도구 호출에 붙일 수 있는 언어 설정·대략적 위치 같은 메타데이터는 읽거나 저장하지 않으며, 추적·광고 쿠키를 쓰지 않습니다. 지원 메일을 보내면 보낸 주소와 내용을 받습니다. 이름·연락처·정밀 위치·결제 정보·대화 내용은 요구하지 않으며, 도구는 개인 URL 과 자유 입력을 거부하도록 만들어져 있습니다.

03

도구가 돌려주는 것

check_incident 는 공개된 호스트 단위 정보만 돌려줍니다. 호스트가 robots.txt·llms.txt 로 선언한 정책, 정리된 공식 개발자·상태 링크, 업체가 발표한 상태, 제보자 신원이 없는 공개 관찰, 대략적인 조회 활동 구간입니다. {% if reporting_enabled %}report_observation 은 관찰·사건 ID, 검토 상태, 그 제보의 철회 토큰이 담긴 접수증을 돌려줍니다. {% endif %}어떤 응답에도 다른 사람의 개인정보는 들어 있지 않습니다.

04

이용 목적

조회에 답하기, {% if reporting_enabled %}제보를 검토·중복 제거·공개하기, {% endif %}남용을 막고 요청 상한을 지키기, 서비스를 운영·보호하고 집계로 측정하기(예: 어떤 공개 호스트명이 조회되는지, 도구 호출이 몇 번 성공하는지), 지원 요청에 답하기입니다. 데이터를 판매하거나 광고에 쓰거나 사람을 프로파일링하거나 AI 모델 학습에 쓰지 않습니다.

05

데이터를 받는 곳

{% if reporting_enabled %}일반 공개: 검토를 통과한 제보는 구조화 필드만 담긴 미검증 관찰로, 제보자 신원 없이 공개 화면과 API·MCP 응답에 나옵니다. {% endif %}조회량은 대략적인 구간으로만 공개합니다. 우리를 대신해 데이터를 처리하는 업체: Cloudflare(네트워크 경계·보안), Render(앱 호스팅·데이터베이스, 미국), Porkbun(지원 주소의 메일 전달)과 그 메일이 전달되는 메일함 업체입니다. 읽기 대상 웹사이트: 호스트의 robots.txt·llms.txt 를 읽을 때 그 호스트는 AgentHelpNetwork 로 표시된 우리 서버의 요청만 보며, 이용자에 관한 정보는 담기지 않습니다. 법이 요구할 때만 당국에 제공합니다. 그 밖의 누구와도 공유하지 않습니다.

06

보존 기간

비밀키로 날짜별 변환한 IP 값과 일별 요청 수: 14일. 유입·캠페인 분류 집계와 결과 범주별 MCP 도구 호출 수: 90일. 호스트별 일일 제보 접수 수: 8일. 조회된 호스트명 목록: 30일 동안 조회가 없으면 삭제(공식 상태 피드가 연결된 호스트는 예외). 공개 호스트명·오류 유형별 일일 조회 수와 경로별 요청 수는 개인정보가 없으며 자동 삭제 기한이 없습니다. {% if reporting_enabled %}제보는 베타 기간 동안 자동 삭제 기한이 없습니다. 공개 조회는 최근 7일만 보여 주고, 철회된 제보는 모든 조회에서 제외되며, 요청하면 삭제합니다. {% endif %}요청 상한 계수는 약 1분간 메모리에만 있고 디스크에 쓰지 않습니다. 지원 메일은 요청 처리에 필요한 동안만 보관합니다. Cloudflare 와 Render 는 자체 전송·보안 기록을 각자의 보존 조건에 따라 보관합니다.

07

이용자의 선택

공개 호스트명과 위의 구조화 코드만 보내세요. {% if reporting_enabled %}접수증의 철회 토큰을 보관하세요. 그 토큰으로 DELETE /v1/observations/{id} 를 보내면 제보가 모든 조회에서 즉시 빠집니다. report_observation 은 별도의 쓰기 작업이라 AI 클라이언트가 확인을 요청할 수 있고, check_incident 는 읽기 전용입니다. {% endif %}ChatGPT 에서 앱 연결을 끊거나 클라이언트에서 MCP 서버를 언제든 제거할 수 있습니다. support@agenthelpnetwork.com 로 제보나 요청에 관해 보관 중인 내용을 묻거나 정정·삭제를 요청할 수 있으며, 제보 ID 가 있으면 함께 적어 주세요. 거주 지역에 따라 열람·삭제·처리 거부 등 추가 권리가 있을 수 있으며 같은 방법으로 행사할 수 있습니다. 30일 안에 답하는 것을 목표로 합니다.

이 서비스는 개발자와 그 에이전트를 위한 것으로 아동을 대상으로 하지 않으며 아동의 데이터를 알면서 수집하지 않습니다. 데이터는 미국에서 처리·저장됩니다. 운영 방식이 바뀌면 바뀌기 전에 이 페이지와 위 날짜를 갱신합니다.
