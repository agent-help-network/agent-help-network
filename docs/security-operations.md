# 개인정보·보안·운영 계획

작성일: 2026-10-03. 로컬 개발과 공개 운영의 요구를 구분한다. 사용자 결정으로 공개 베타의 가입 없는 제보를 열고, 아래의 기존 사전 게이트 중 키 발급·자동 보존 삭제(제보는 `AHN_REPORT_RETENTION_DAYS` 를 설정한 경우에만)·백업 복구 리허설은 후속 위험으로 관리한다. 실제 접수 절차는 [공개 제보 운영 절차](public-intake-operations.md)를 따른다. [OWASP ASVS](https://owasp.org/projects/asvs), [API Security Top 10](https://api-security.owasp.org/editions/2023/en/0x11-t10/), [PostgreSQL 백업 문서](https://www.postgresql.org/docs/current/backup.html)를 검수 기준으로 참고한다.

## 로그와 비밀 관리

키는 요청 헤더에서만 받고 URL/쿼리/오류 응답에 넣지 않는다. 원문 요청 본문, 쿠키, 계정명, 개인 URL을 로그에 남기지 않는다. 감사 이벤트에는 사건/관찰 내부 ID, 작업 유형, 시각 정도만 넣는다. `.env`, 키 파일, DB 데이터, 덤프, 런타임 로그는 Git에서 제외한다. 실제 자격 증명은 README에 적지 않는다.

## 제보 동의와 공개 흐름

읽기와 쓰기는 분리한다. 제출 에이전트는 자신의 사용자·플랫폼 권한 규칙을 따르며, 허용되는 범위에서 비식별 관찰을 자동 전송할 수 있다. 서비스의 안내는 외부 에이전트에게 권한을 부여하지 않고 특정 건별 승인 절차도 강제하지 않는다. `consent_confirmed`는 호환용 선택 필드이며 서버가 권한을 증명하는 신호로 사용하지 않는다. 제출 후 실제 제보는 `pending`에 두고, 민감 정보·허위 내용 검토를 거쳐 공개한다. 합성 시험 데이터는 공개 사건 페이지에 나타나지 않는다.

## 운영 준비 게이트

현재 베타는 닫힌 입력 필드, 규칙 기반 자동 검토·보류, 관리자 숨김, 제보자 철회 토큰, 분당·일일 속도 제한, HTTPS, 비공개 DB 연결을 우선 적용한다. 자동 검토로 공개된 자료는 진위가 확인된 사실이 아니라 **미확인 관찰**이다. Render의 별도 Cron Job에서 비용 경고·웹 서비스 중단 시도도 가동 중이며 실제 대역폭 조회는 검증했다. 다만 임계값에서의 실제 중단과 이메일 전달은 확인하지 못했고 결제 hard cap도 아니다. 셀프서비스 키 발급, 백업과 **복구 시험**은 아직 미완료이고, 제보의 자동 삭제는 `AHN_REPORT_RETENTION_DAYS` 를 설정한 경우에만 동작한다. 단순한 `pg_dump` 생성만으로 복구 가능성을 증명하지 않는다. 유입이나 악용이 늘면 접수를 멈추고 이 통제를 우선 보강한다. 호스팅 비용·트래픽 안전장치(비공개 운영 기록)의 과금 위험도 계속 유효하다.

Muse 커넥터 약관은 사용자 데이터의 필요한 기간 내 보관·철회/삭제 처리와 보안 사고 통지 의무를 포함한다. 호스트 조회 등록부(`queried_hosts`)는 30일 동안 조회가 없으면 삭제한다(활성 상태 출처가 있는 호스트 제외, `platform_metrics.prune_analytics`). 제보는 운영자가 `AHN_REPORT_RETENTION_DAYS` 를 설정한 경우에만 자동 삭제하며, 설정하지 않으면 자동 삭제 일정이 없다. Muse 접수는 2026-10-03 완료됐지만, **승인 전까지 보존 기간·삭제 요청 처리·사고 통지 절차를 약관과 대조해 운영상 공백을 해소해야 한다.** 접수 또는 심사가 현재 구현의 준수를 보증하지 않는다.

## 사고 발생 시 초안 절차

1. 제보 또는 키 유출 의심을 확인하면 해당 쓰기 키를 비활성화하고 공개 범위를 제한한다.
2. 민감 데이터가 노출됐는지 로그/DB/백업을 확인한다. 조사 기록 자체에는 민감 원문을 복사하지 않는다.
3. 잘못된 관찰은 숨기거나 철회하고, 필요하면 관련 공개 요약을 갱신한다.
4. 복구 후 재현 시험과 회귀 시험을 실행하고 원인 및 개선 조치를 기록한다.

이 문서는 법률 자문이나 완성된 운영 정책이 아니다. 실제 공개 전 관할·이용자에 맞는 정책을 확정한다.
